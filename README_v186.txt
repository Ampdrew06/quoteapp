Timberlite v186 - apply over v185
Overwrite included src files; add the new EdwardianFacetEditor and edwardianSideLayout files.

Edwardian admin D/O now has Edit facet: Facet1/RB1 left, Facet2/RB2 front, Facet3/RB3 right. Centre, gap-from-previous and gap-to-next input fields are provided. Changing a gap moves that member only. The final gap is to the internal front/side corner. Apply changes validates the full manufacturing/material model before updating.

Side facets: wall truss locked at31.5mm from house wall. Intermediate trusses can be moved, added or removed; their positions are shared across both side facets, since each is one full truss. Side jacks can be moved, added or removed independently on left/right. Members cannot cross the boss truss, overlap slots or hip seats. Add after selects truss/jack according to the current zone. Boss truss is movable but not removable.

Boss/front-pitch coupling: moving boss centre to B sets ridge point B+33mm and recalculates front pitch from the existing rise and remaining front run. Side pitch and roof height stay unchanged. The Adjust front pitch control then shows the derived pitch. Later editing that pitch moves the boss truss, including the endpoint of a manually spaced truss layout. Existing ordinary manual truss/jack centres stay fixed; if a moved boss collides with them, edit those positions before applying. Existing admin front-pitch range applies; overlapping/non-positive cut layouts are rejected.

Restore automatic spacing on either side restores shared automatic truss spacing and that side's jack spacing, preserving the selected front pitch and the opposite side's manual jacks. Facet2 retains Restore automatic layout. Manual layouts are stored in saved quote inputs and feed CAD, ringbeam slots/upstands, joists/PIR, hardware/fixings, Summary prices, manufacture and checklist. Other roof-style editors remain unchanged; Victorian geometry explicitly ignores Edwardian manual fields.
